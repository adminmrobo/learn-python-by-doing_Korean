    저녁 일곱 시, 장부가 도착했다
    "이 숫자, 정말 맞아요?"

    동네 상가 2층 장부 상담소. 카페 Koi, 동네 편의점, 의류 쇼핑몰 사장님들이 장부를 들고 찾아옵니다. 파이썬을 몰라도 괜찮습니다. 한 절에 한 가지씩, Colab 에 코드를 붙여 넣고, 결과를 이 사이트와 맞춰 보고, 다음 절로 넘어가면 됩니다.

    글 · 안상선 ((주)M-Robo 대표)

    LOG 19:00 장부 상담소

    첫 장부 상자가 책상에 올라온 직후의 기록입니다.

    [SYSTEM] 의뢰 3건 접수. 첨부: 영수증 CSV, 원가표 엑셀, 배달앱 JSON, 환율 백업, AI 가 만든 가격표. 요청: "이 숫자, 맞는지 봐 주세요."
    조수코드는 처음인데, 정말 따라 할 수 있을까요? 일단 장부 상자는 제가 열어 볼게요!
    박사한 절에 한 가지만 해요. 숫자는 늘 화면에 보이게 하고요. 그리고 그림보다 검증이 먼저다.
    초파리 연구원원가표 이름 끝에 공백이 숨어 있는 거 봤어? 장부는 늘 한 번 더 의심해야 해.
    Money-Robo삐빅, 대기 중. 검증 셀을 돌리면 내 불빛이 초록이 될 거야!

    ORDER 상담소 의뢰서

    ■ 장부 정리 · 상담소 전원

    질문
    가게 장부의 숫자를 파이썬으로 어떻게 읽고, 맞추고, 한 장으로 보여 주는가?
    방법
    한 절 10~15분. 코드 붙여 넣기 → 실행 → 결과 맞춰 보기 → 읽는 법 → 바꿔 보기
    준비물
    구글 계정 하나. 편마다 실습 zip 하나. 설치할 것은 없다
    권장 순서
    0편 → 1편 → 2편 → 3편 → 4편 → 마감. 끝낸 절은 체크하면 이 기기에 기억된다

    MISSIONS 의뢰 다섯 건과 마감

    "▶ 시작"을 누르면 그 편의 첫 페이지로 갑니다. 절마다 "끝냈어요"를 체크하면 여기 진행이 채워집니다.

    0 / 46

    KIT 절마다 들어 있는 것

    ▣ Colab 코드

    코드 블록마다 복사 버튼이 있습니다. Colab 새 노트를 열고 한 블록씩 붙여 넣어 실행합니다.

    ▣ 실제 실행 결과

    모든 결과와 그림은 코드를 실제로 돌려 얻었습니다. 내 화면과 숫자를 맞춰 봅니다.

    ▣ 읽는 법 · 바꿔 보기

    결과를 어떻게 읽는지 짚고, 숫자 하나를 바꿔 다시 돌려 보게 합니다.

    ▣ 함정과 검증

    숨은 공백, 중복 영수증, 주말 환율, 100엔 고시. 실제로 걸려 넘어지는 곳을 일부러 넣었습니다.

    ▣ 식구들의 한마디

    조수가 대신 묻고, 박사가 답하고, 초파리가 의심하고, Money-Robo 가 불빛으로 알려 줍니다.

    ▣ 가게 데이터

    회계 용어 없이 카페 · 편의점 · 쇼핑몰 장부로 배웁니다. 숫자는 모두 연습용입니다.
